# Noughts & Crosses

Tic-tac-toe in the browser, styled like a game on the back page of a notebook. The marks and grid lines are hand-drawn SVG, so every round looks a little different.

## Play

Play online at **https://hernanislb1904.github.io/tic-tac-toe/**

Or open `index.html` in any modern browser (double-click it). There's nothing to install and no build step.

## Features

- Play against the computer or a friend on the same device
- Three computer levels: **Sloppy** (mostly random), **Tricky** (usually plays the best move), and **Perfect** (never loses, using minimax search)
- Players take turns starting each round
- Running score kept as tally marks
- Light and dark mode follow your system setting

## Tech

Plain HTML, CSS, and JavaScript in one file. Fonts load from Google Fonts, and the page falls back to system fonts when offline.
